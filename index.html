About the Project

The Smart Blind Stick project aims to improve mobility and independence through electronic sensors and location technology.

Obstacle Detection

An ultrasonic sensor can detect obstacles in front of the stick.

GPS Location

A GPS module provides geographical coordinates outdoors.

Wi-Fi Connectivity

An ESP8266 can transmit location data when connected to a suitable service.

Camera Support

An ESP32-CAM can support future camera-based assistance features.
