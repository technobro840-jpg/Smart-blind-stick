Project Features

Obstacle Detection

Ultrasonic sensors detect nearby obstacles and help provide safer movement for the user.

GPS Tracking

The NEO-6M GPS module can provide the user's geographical location.

ESP8266 Wi-Fi

ESP8266 provides wireless communication for sending information to online systems.

ESP32-CAM

The ESP32-CAM can provide camera-based monitoring and visual information.
