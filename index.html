Project Features

Obstacle Detection

Ultrasonic sensors detect nearby obstacles and help improve safety for the user.

GPS Tracking

The NEO-6M GPS module can provide geographical location information.

ESP8266 Wi-Fi

ESP8266 provides wireless communication for sending information to online systems.

ESP32-CAM

ESP32-CAM provides camera-based monitoring and visual information.
